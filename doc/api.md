# 例（リアクションの登録API）

1. APIの持つ機能

- 展示作品に対して、来場者が「いいね」を登録できる。
- 指定された展示作品に「いいね」を追加する
- 展示作品が存在するか確認する
- 同一来場者による重複登録を防止する（発展）
- 登録後のリアクション総数を取得して返す
- ログインなしで利用できる

2. HTTPリクエストメソッド

- POST

3. URL

- `POST /api/v1/exhibits/{exhibit_id}/reactions`

4. レスポンス形式

```
   {
   "exhibit_id": 123,
   "reaction_count": 21
   }
```

# 来場者数集計API

1. APIの持つ機能
-当日のチェックイン数（延べ人数）を集計する
-日別のチェックイン数を集計する（F-15）。
-時間別のチェックイン数を集計する（F-16）。
-日本時間（Asia/Tokyo）を基準に集計する。
-集計結果をJSON形式で返す。
-チェックイン記録が存在しない場合、当日のチェックイン数は0件として返す。
-ログインなしで利用できる。


2. HTTPリクエストメソッド

- GET

3. URL

- `GET /api/v1/checkins/stats`

4. レスポンス形式

```
   {
  "today": {
    "date": "2026-10-26",
    "count": 120
  },
  "daily": [
    {
      "date": "2026-10-25",
      "count": 80
    },
    {
      "date": "2026-10-26",
      "count": 120
    }
  ],
  "hourly": [
    {
      "hour": "2026-10-26T10:00:00+09:00",
      "count": 35
    },
    {
      "hour": "2026-10-26T11:00:00+09:00",
      "count": 42
    }
  ]
}
```
